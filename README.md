## 💻 Interactive Terminal CLI (`tarun_profile.exe`)

The hero section features a real in-browser terminal emulator. You can type commands directly into the terminal or click the quick command chips:

| Command | Action / Output |
| :--- | :--- |
| `whoami` | Displays professional headline & identity summary |
| `cat credentials.json` | Outputs academic scores, batch, and core technical stack |
| `./check_profiles.sh` | Generates verified, clickable links to LinkedIn, GitHub, & LeetCode |
| `skills` | Outputs full technical arsenal across languages, core CS, and ML |
| `projects` | Summarizes featured repositories with a smooth-scroll anchor |
| `education` | Displays B.Tech, 12th, and 10th academic achievements |
| `contact` | Reveals direct contact coordinates |
| `resume` | Directly opens / downloads the official PDF resume |
| `help` | Prints all supported terminal commands |
| `clear` | Resets and clears the terminal session |

## 💻 Local Development & Setup

You can run this portfolio locally without any external dependencies or build steps:

### 1. Clone the repository:
```bash
git clone https://github.com/Tarundobhal/tarun-portfolio.git
cd tarun-portfolio
```

### 2. Run locally:
Simply open `index.html` in your favorite web browser:
```bash
# Windows PowerShell
Start-Process index.html

# Or run using any lightweight HTTP server:
npx serve .
```

## ☁️ Deployment on Vercel

This portfolio is pre-configured for seamless 1-click deployment on **Vercel**:

1. Fork or clone this repository.
2. Visit [vercel.com/new](https://vercel.com/new) and log in with your GitHub account.
3. Import `Tarundobhal/tarun-portfolio`.
4. Leave settings as default (Static Site) and click **Deploy**.
5. Your live portfolio will be deployed with automatic SSL and continuous deployment on every `git push`!
